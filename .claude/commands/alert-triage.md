Dependabotの警告を整理し、対応の要否と方法を提案する。`.claude/skills/dependency-alert-triage/SKILL.md` に従うこと。

`$1` が指定されている場合は、そのパッケージ名または警告番号の警告だけを対象にする。省略時は未対応(open)の全件を対象にする。

以下を順に行う。

1. **取得**: スキルの手順1・2に従い、警告を取得し、Rustは `cargo audit` と突き合わせる。同じパッケージの警告はまとめる。
2. **到達性の確認**: スキルの手順3に従い、パッケージごとに `cargo tree` / `npm ls` を実行して、配布物に入るかを確認する。出力を根拠として残し、推測で分類しない。
3. **重み付けと修正可能性**: スキルの手順4・5に従い、このアプリの脅威モデルでの優先度と、修正版の有無・更新の規模を確認する。
4. **分類と報告**: スキルの4区分(A 要対応 / B まとめて更新 / C dismiss候補 / D 様子見)に分類し、スキルの報告形式で提示する。
5. **ここで止まる**: dismiss・Issue起票・依存更新・設定変更は実行しない。提案を提示し、どれを実行するかをユーザーに確認する。承認された操作だけを、スキルの実行ゲートに従って実行する。
