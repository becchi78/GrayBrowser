# インストールと初期設定

GrayBrowser をインストールして、最初の動画フォルダを登録するまでの手順と、メニュー・設定の一覧をまとめたガイドです。

関連ガイド: [README](../README.md) / [フォルダ登録・スキャンの詳細](folder-scan.md) / [タグ・レーティングの活用法](tags-and-rating.md) / [重複ファイルの管理](duplicate-files.md) / [データベースのバックアップと復元](backup.md) / [旧WhiteBrowser(.wb)からの移行](wb-import.md)

## 動作環境

- Windows(64bit)
- WebView2 Runtime(多くのWindows環境には標準で入っています)
- FFmpeg / FFprobe(GrayBrowser には同梱されていません。次の節を参照してください)

## FFmpeg / FFprobe を用意する

サムネイルの生成とメタデータ(解像度・コーデック・再生時間など)の取得に、FFmpeg と FFprobe を使います。どちらも別途インストールし、PATH を通しておく必要があります。

1. FFmpeg を入手します。配布元は [FFmpeg の公式サイト](https://ffmpeg.org/)から辿れます。
2. `ffmpeg.exe` と `ffprobe.exe` が入っているフォルダを、環境変数 PATH に追加します。
3. GrayBrowser を(起動中なら一度終了して)起動し直します。

見つからない場合は、画面に次のバナーが表示されます。

> FFmpeg / FFprobe が見つかりません。PATH に追加すると、サムネイルが自動的に生成されるようになります。

FFmpeg の場所を GrayBrowser の画面で指定する機能はありません。PATH だけが対象です。PATH を追加したあとにバナーが消えない場合は、GrayBrowser を再起動してください。

サムネイルが作られなかった動画は、FFmpeg / FFprobe を使えるようにしたあとで、ステータスバーの「生成失敗」パネルからまとめて作り直せます。詳しくは[サムネイルとメタデータの生成失敗](folder-scan.md#サムネイルとメタデータの生成失敗)を参照してください。

## インストール

1. [Releases](https://github.com/becchi78/GrayBrowser/releases/latest) ページから、最新のインストーラー(`GrayBrowser_x.y.z_x64-setup.exe`)をダウンロードします。
2. ダウンロードしたファイルを実行します。管理者権限は不要で、ユーザー単位でインストールされます。

### SmartScreen の警告が出たとき

インストーラーはコード署名をしていないため、Windows SmartScreen の警告(「Windows によって PC が保護されました」)が出ることがあります。ダウンロード元が Releases ページであることを確認したうえで、「詳細情報」をクリックし、表示された「実行」ボタンをクリックしてください。SHA256 ハッシュでファイルを確認する方法は、[README](../README.md#windows-smartscreen-の警告について)にあります。

## 最初のフォルダを登録する

1. メニューの「ファイル > フォルダ管理...」を開きます。
2. 「+ フォルダを追加」を押し、動画が入っているフォルダを選びます。複数のフォルダを登録できます。
3. 追加した時点で、そのフォルダの動画が自動的に登録されます。「再スキャン」を押す必要はありません。
4. サムネイルとメタデータは、バックグラウンドで順番に作られ、一覧に反映されます。作成の進み具合は、ステータスバーに表示されます。

フォルダ管理でできることの詳細は、[フォルダ登録・スキャンの詳細](folder-scan.md)を参照してください。旧WhiteBrowser のデータがある場合は、[旧WhiteBrowser(.wb)からの移行](wb-import.md)を参照してください。

## メニューの構成

| メニュー | 項目 | 内容 |
| --- | --- | --- |
| ファイル | フォルダ管理... | 動画フォルダの追加・並べ替え・登録解除・再スキャン |
| ファイル | .wbインポート... | 旧WhiteBrowser の `.wb` ファイルを取り込む |
| ファイル | データベースをバックアップ | 手動でバックアップを取る |
| ファイル | 終了 | アプリを終了する |
| タグ | タグの編集... | タグの並び替えと削除 |
| スタイル | Default | 現在選べるスタイルは Default だけです |
| 設定 | 設定... | 設定ダイアログを開く |
| ヘルプ | 動作ログ... | 現在のログを確認する |
| ヘルプ | 更新の確認... | 新しいバージョンを確認して更新する |
| ヘルプ | バージョン情報 | バージョンなどを表示する |

## 設定

メニューの「設定 > 設定...」で開きます。

| 項目 | 内容 |
| --- | --- |
| NAS・ネットワークドライブの確認間隔 | 1〜1440 分で指定します(既定は 10 分)。ネットワークドライブ上のフォルダの変更を、この間隔で確認します。ローカルドライブは変更を検知して即座に反映するため、この設定は関係しません。 |
| 起動時に更新を確認する | オフにしても、「ヘルプ > 更新の確認...」からいつでも確認できます。 |
| 前回終了時の検索・フォルダなどの状態を、起動時に復元する | 検索語、フォルダ、並び順、タグ、評価の絞り込みを復元します。オフにすると、保存済みの状態も消去されます。 |

「既定に戻す」で全項目が初期値(確認間隔 10 分、2つのチェックはオン)に戻ります。変更を反映するには「保存」を、取りやめるには「キャンセル」を押します。

## アプリ内アップデート

新しいバージョンがあると、起動の数秒後に「新しいバージョン X があります」と通知されます。「詳細・更新」を押すと更新の確認ダイアログが開き、「あとで」を押すと、その起動中は通知されません。

メニューの「ヘルプ > 更新の確認...」からも、いつでも確認できます。

1. 新しいバージョンがあるときは、「今すぐ更新」を押します。
2. 更新ファイルのダウンロード後に、署名を検証してインストーラーが起動します。
3. アプリは自動的に終了し、更新が終わると再起動します。

更新は、「今すぐ更新」を押したときだけ行われます。登録したフォルダやタグなどのデータは変わりません。

## バックアップ

「ファイル > データベースをバックアップ」で、タグやレーティングなどのデータをいつでもバックアップできます。アプリの更新でデータベースの移行が必要なときは、移行の直前にも自動で取得します。保存先や復元の手順は、[データベースのバックアップと復元](backup.md)を参照してください。

## 動作ログとバージョン情報

- 「ヘルプ > 動作ログ...」で、現在のログをアプリ内で確認できます。
- 「ヘルプ > バージョン情報」で、いま使っているバージョンを確認できます。
