# 旧WhiteBrowser(.wb)からの移行ガイド

旧WhiteBrowserで管理していた動画の一覧を、GrayBrowserへ引き継ぐ手順をまとめたガイドです。

## 1. 移行できるもの・できないもの

`.wb` ファイルから次の情報を取り込みます。

- **動画のパス**(ファイルの場所)
- **タグ**
- **レーティング**(星1〜5)
- **読み仮名**(検索で使われます)
- **旧サムネイル**(ただし、取り込めるのは「現在つながっていない(オフラインの)動画」のものだけです。詳しくは[「オンライン動画とオフライン動画でサムネイルの扱いが違います」](#5-オンライン動画とオフライン動画でサムネイルの扱いが違います)を参照)

次の情報は移行しません。

- 再生回数
- 旧WhiteBrowserの検索履歴・画面設定・タグバーの設定、およびその監視フォルダ設定(ただし、取り込んだ動画のフォルダを監視フォルダへ追加する機能はあります。[「4.」](#4-結果画面の見方)参照)

`.wb` ファイルは読み取り専用で開くため、元のファイルが書き換えられることはありません。

## 2. 事前準備

インポートには次の2つを指定します。

### `.wb` ファイル

旧WhiteBrowserのデータベースファイル(拡張子 `.wb`)です。移行したいライブラリのものを用意してください。

### 旧サムネイルフォルダ

旧WhiteBrowserが作ったサムネイル画像(JPG)が入っているフォルダです。ファイル名は次のような形式です。

```
動画のファイル名.#1e5e0fbf.jpg
```

`#` の後ろの8桁の小文字の英数字(`0`〜`9` と `a`〜`f`)が、その画像がどの動画のものかを示す目印です。GrayBrowserはこの目印だけで画像と動画を対応づけます。**フォルダ名や、画像ファイル名のうち動画名の部分は、対応づけには使いません。**

選ぶときのポイントは次のとおりです。

- 上記の形式のJPGが**直接入っているフォルダ**を選んでください。サブフォルダの中までは探しません。
- 画像と動画の対応づけは上記の目印だけで決まり、フォルダ名やサムネイルのサイズ設定は見ません。どのサイズのフォルダでも、上記の形式の画像が直接入っていれば対応づきます。複数のフォルダがある場合は、上記の形式の画像が入っているフォルダを選んでください。
- スキン(見た目の設定)ごとのフォルダ構成は、確認できている範囲が限られています。フォルダが見つからない・どれか分からない場合は、JPGが入っているフォルダを開いて、上記の形式のファイル名かどうかを確かめてください。
- 動画がすべて現在つながっている(オンラインの)場合、旧サムネイルは使われず、動画本体から新しく作られます。この場合でも、画面上は旧サムネイルフォルダの指定が必要です。

## 3. 操作手順

1. GrayBrowserを起動し、メニューの「ファイル」から「.wbインポート...」を選びます。
2. 「.wbファイルを選択」を押して、`.wb` ファイルを選びます。
3. 「旧サムネイルフォルダを選択」を押して、旧サムネイルが入っているフォルダを選びます。
4. 「インポート」を押します。両方のファイル/フォルダを選ぶまで、このボタンは押せません。
5. 進み具合が表示されます。完了するまでは「閉じる」を押せません。画面の外側をクリックしても閉じません(「閉じる」ボタンで閉じます)。閉じて開き直すと、前回の選択や結果は残らず、ファイル選択から始まります。
6. 完了すると結果画面に切り替わります。内容は次の章を参照してください。

同じ `.wb` をもう一度インポートしても、すでに登録済みの動画は重複して登録されません(「登録済みのためスキップ」として数えられます)。

### 監視フォルダの自動追加

インポートした動画のフォルダは、自動で監視フォルダに追加されます。不要なフォルダは、あとから監視フォルダの設定で外せます。

- 今回登録した動画(オンライン・オフラインとも)のフォルダが監視フォルダに追加され、サイドバーに表示されて、以降の新しいファイルも自動で検知されます。NASが停止中などでつながっていないフォルダもサイドバーに表示され、その配下の動画の行に「⚠ オフライン」と表示されます(フォルダ自体にはオフラインのバッジは付きません)。
- 追加されないフォルダがあります。ドライブ直下(`D:\` など)、ネットワーク共有のルート、すでに登録済みの監視フォルダと同じ・内側・外側の関係にあるフォルダです。追加先同士が包含関係にある場合は、外側の1つにまとめます(関係のない兄弟フォルダへは広げません)。また、登録済みのためスキップした動画のフォルダ(再インポート時)や、パスの途中に復元できなかった文字(`?`)が残っているフォルダも追加されません。

## 4. 結果画面の見方

結果画面の表示項目と意味です。項目名は画面の表示にそろえています。結果画面は次の3つに分かれています。

- **主表示**: 次の行が並びます。
  - 「.wb内の動画: T件」
  - 「インポート: N件(オンライン X件 / オフライン Y件)」
  - オフライン動画が1件以上のときだけ「オフライン動画の旧サムネイル紐付け成功: M件(Y件中)」
  - 監視フォルダを追加したときだけ「監視フォルダに追加: K件」
  - 「登録済みのためスキップ: S件」(0件なら出ません)
- **要対応**: 目立つ色の枠で表示します。該当があるときだけ出ます。「自動対応できなかった旧サムネイル」「旧サムネイル変換に失敗」「機種依存文字のため未登録」「取り込めなかった行」、およびタグが付与されなかった疑いがあるとき(「タグをインポート」の「要確認」または「インポートに失敗した可能性があります」)です。
- **詳細**: 「詳細」を開くと見える内訳です。タグをインポート、score丸め、追加した監視フォルダの一覧です。**件数が0の項目は表示しません。**

結果画面の表示は今後変わる可能性がありますが、意味は同じです。

### 件数の突き合わせ

`.wb` の動画1件1件は、必ず次のどれか1つに数えられます。このため、次の等式がいつも成り立ちます。

> **.wb内の動画 = インポート(オンライン + オフライン) + 登録済みのためスキップ + 機種依存文字のため未登録 + 取り込めなかった行**

0件の項目は画面に出ないので、出ていない項目は0件として足してください。すべて登録済みの動画を再インポートしたときは、「インポート: 0件」と「登録済みのためスキップ」の件数で、「.wb内の動画」と一致します。

### .wb内の動画

`.wb` に入っている動画(行)の総数です。

### インポート

今回、新しく登録した動画の件数です。パス・タグ・レーティング・読み仮名が取り込まれています。対応は不要です。動画ファイルが手元にあるか(オンライン)、見つからないか(オフライン)の内訳が、かっこ内に出ます。

### オフライン動画の旧サムネイル紐付け成功

オフライン動画のうち、旧サムネイルを取り込んで動画に紐付けられた件数です(「Y件中」は今回インポートしたオフライン動画の件数)。オフライン動画が無いときは表示されません。オンライン動画の旧サムネイルは取り込まず、動画ファイルから別途作るため、この件数には含まれません。結果画面には、オンライン動画のサムネイルについての件数や注記は表示しません。

### 登録済みのためスキップ

同じパスの動画がすでにGrayBrowserに登録されていたため、取り込まなかった件数です。エラーではありません。

登録済みの動画のレーティング・タグなどは**書き換えません**。GrayBrowser側で編集した内容が、古い `.wb` の内容で上書きされないようにするためです。

### 取り込めなかった行

日付の形式が読み取れない、データベースへの書き込みに失敗した、などの理由で、取り込めなかった動画(行)の件数です。ほかの動画のインポートは続行されます。0件のときは表示されません。

### 機種依存文字のため未登録

ファイル名に機種依存文字(丸数字、ローマ数字、㈱ など)を含む動画は、通常のスキャンと同じく**登録しません**。その件数です。該当する動画はステータスバーの「未登録」パネルに表示されます。ここで機種依存文字を取り除いた名前に変更すると、通常の動画として登録されます。

- 判定はファイル名だけで行い、オフライン動画(ファイルが見えない行)も同じ扱いです。パスの `?` を復元できた行は、復元後の名前で判定します。
- 登録しない動画の旧サムネイルは、「自動対応できなかった旧サムネイル」には数えません。
- 該当する動画のフォルダは、監視フォルダの自動追加の対象にもなりません。
- 同じ `.wb` をもう一度インポートしても、「未登録」の一覧に重複して載ることはありません。

### score丸め

旧WhiteBrowserのscore(評価)は星1〜5の範囲を超える値(20などの値)を持てました。GrayBrowserの評価は星1〜5なので、`.wb` の中で**scoreが6以上だった動画の数**です。これらは星5として扱い、段階に応じて割り振り直すことはしません。この件数は `.wb` 全体で数えるため、登録済みでスキップされた動画や、★タグの評価が優先された動画も含まれます。対応は不要です。

### タグをインポート

登録した動画に付けたタグの延べ件数です(詳細)。`.wb` にタグがもともと無い場合や、すべて登録済みでスキップされた場合は0件になり、この項目は表示されません。元データにタグがあるのに付与されなかった場合は、要対応として「要確認」と表示されます。

### ★だけのタグの扱い

旧WhiteBrowserでは、`★` や `★★★` のような**★だけのタグ**を評価代わりに使う運用がありました。GrayBrowserではこのようなタグを通常のタグとしては登録せず、★の数(最大5)をレーティングにします。結果画面には、この件数は表示しません。

- 動画に★タグとscoreの両方がある場合は、★タグを優先します。★タグが複数ある場合は最大のものを使います。
- `☆` や `★お気に入り` のように、★以外の文字を含むタグは通常のタグのままです。
- 新しく登録した動画だけが対象で、スキップした動画は対象外です。

### 監視フォルダに追加

実際に追加されたフォルダの件数(主表示)と、そのフォルダの一覧(詳細)です。

### 自動対応できなかった旧サムネイル

旧サムネイルフォルダ内のファイルのうち、オンライン動画にもオフライン動画にも対応づけられなかったファイルの件数です。エラーではありません。次のようなファイルが該当します。

- 命名規則に合わないファイル(`Thumbs.db` など、JPG以外も含みます)
- 今回の `.wb` に存在しない動画の画像
- サブフォルダ(中は探しませんが、サブフォルダ自体の名前も件数に含まれることがあります)

件数が少ない場合は、通常は気にする必要はありません。オフライン動画があるのに大半が対応できなかったときは、命名規則の画像(`…#xxxxxxxx.jpg`)が入っていない別のフォルダを選んだ可能性があります。なお、登録済みのオフライン動画の旧サムネイルは再インポートでは取り込み直されません([「5.」](#5-オンライン動画とオフライン動画でサムネイルの扱いが違います)参照)。

対象のファイルは、選択した旧サムネイルフォルダ内にそのまま残っています。なお、これらを手動で紐付ける機能は現在ありません。

### 旧サムネイル変換に失敗

対応づけはできたものの、画像の変換(JPGからGrayBrowser用の形式への変換)や保存に失敗した件数です。この項目が表示されなければ(0件であれば)問題ありません。1件以上ある場合は、その動画のサムネイルは未設定のままです。

### 旧サムネイル紐付け成功

オフライン動画に旧サムネイルを紐付けられた件数です。紐付けに成功した旧サムネイルは、そのオフライン動画のサムネイルとして表示されます。

## 5. オンライン動画とオフライン動画でサムネイルの扱いが違います

インポート時に、動画ファイルが今そのパスに存在し読み取れるかどうかで、扱いが分かれます。

| 種類 | 状態 | サムネイル |
| --- | --- | --- |
| オンライン動画 | 動画ファイルが手元にある | 旧サムネイルは使わず、動画本体から新しく生成します(バックグラウンドで順次表示されます) |
| オフライン動画 | 動画ファイルが見つからない(外付けHDDを外している、など) | 旧サムネイルフォルダの画像を取り込んで表示します。6コマが横に並んだ画像(`200x150x6x1`の設定)は、6つのコマに切り分けて取り込みます |

- 動画ファイルがつながっていなくても、カタログ(パス・タグ・レーティング)と旧サムネイルは取り込めます。外付けHDDの動画を、HDDなしで一覧できるようにするためです。
- 同じ `.wb` を再インポートしたとき、すでに登録済みのオフライン動画の旧サムネイルは取り込み直しません。旧サムネイルを取り込みたい場合は、先に旧サムネイルフォルダを正しく選んだうえで、はじめてのインポートを行うのが確実です。
- 画像の大きさが`.wb`のサムネイル設定と合わない場合や、設定を読み取れなかった場合は、切り分けずに画像全体をそのまま取り込みます。
- 旧サムネイルフォルダの画像が見つからない動画は、サムネイルが未設定のままになります。移行自体は成功として扱われます。

## 6. うまくいかないとき

- **「移行に失敗しました」と表示された**: `.wb` ファイルが読み取れない可能性があります。別の `.wb` ファイルで試すか、ファイルが壊れていないか確認してください。
- **オフライン動画のサムネイルが出ない**: 旧サムネイルフォルダの選択を確認してください。結果画面の「自動対応できなかった旧サムネイル」が多い場合は、命名規則の画像(`…#xxxxxxxx.jpg`)が入っていない別のフォルダを選んだ可能性があります。

## 確認できている範囲について

このガイドの内容は、特定のスキン・サムネイルサイズ設定(`200x150x6x1`)を使っていた `.wb` での確認結果と、実装の挙動に基づいています。ほかのスキンや設定のフォルダ構成は確認できていません。また、旧WhiteBrowserがサムネイルのフォルダをどのような名前・構成で作るかは、このガイドでは確認できていません(GrayBrowserは名前を使わず、フォルダ直下の画像のファイル名だけで対応づけます)。
