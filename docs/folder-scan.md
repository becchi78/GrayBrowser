# フォルダ登録・スキャンの詳細

動画フォルダの登録、スキャン、フォルダの監視、接続できないフォルダ(オフライン)の扱い、登録できなかったファイルへの対処をまとめたガイドです。

関連ガイド: [README](../README.md) / [インストールと初期設定](getting-started.md) / [タグ・レーティングの活用法](tags-and-rating.md) / [重複ファイルの管理](duplicate-files.md) / [旧WhiteBrowser(.wb)からの移行](wb-import.md)

## フォルダ管理ダイアログ

メニューの「ファイル > フォルダ管理...」で開きます。登録したフォルダが1行ずつ並び、各行で次の操作ができます。

| 項目 | 内容 |
| --- | --- |
| ↑ / ↓ | フォルダの並びを入れ替えます。 |
| パス | 登録しているフォルダのパスです。 |
| 更新チェック | オンのフォルダだけが、再スキャンの対象になります。動画が増えないフォルダは、オフにできます。 |
| ✎(パスを編集) | GrayBrowser に登録しているパスを書き換えます。エクスプローラーなどでフォルダを移動・改名したあとに、登録を新しい場所へ合わせるための操作で、ディスク上のフォルダは変わりません。配下の動画は、タグ・レーティング・登録日などを保ったまま、新しいパスに付け替えられます。「保存」で確定し、「キャンセル」で取りやめます。他の登録フォルダと重なる(同じ、または内側・外側になる)パスには変更できません。 |
| ✕(フォルダの登録を解除) | 確認ダイアログのあとで、登録を解除します。 |

下部のボタンは次のとおりです。

- 「+ フォルダを追加」: フォルダを選んで登録します。
- 「再スキャン」: 「更新チェック」が入っているフォルダを、あらためて全件確認します。すべてのフォルダで「更新チェック」が外れているときと、フォルダが1つも登録されていないときは押せません。
- 「閉じる」: ダイアログを閉じます。

### 登録の解除について

「登録を解除する」を押すと、そのフォルダ配下の動画について、GrayBrowser 上のタグ・レーティング・登録日の情報が失われます。確認ダイアログには、対象の動画の件数が表示されます。動画ファイル自体は削除されません。

### 追加すると自動でスキャンされます

フォルダを追加すると、中の動画が自動的に登録され、フォルダの監視も始まります。「再スキャン」は、登録内容をあらためて全件確認したいときに使うもので、追加のたびに押す必要はありません。

### 再スキャンの結果表示

「再スキャン」が終わると、ボタンの横に結果が1行で表示されます。

| 表示 | 意味 |
| --- | --- |
| 検出 | 見つかった動画の数 |
| 登録 | 新しく登録した数 |
| 更新 | すでに登録済みで、情報を更新した数 |
| 変化なし | 変わっていなかった数 |
| スキップ | 登録しなかった数(機種依存文字を含むファイル名など。[「未登録」パネル](#未登録パネル)を参照) |
| オフライン化 | 見つからなくなり、オフラインにした数 |
| 復帰 | オフラインだった動画が、別のパスで見つかり、元に戻った数(同じパスで戻った動画は「更新」に数えます) |

接続できないフォルダがあって飛ばしたときは、末尾に「到達できないため飛ばしたフォルダ: N 件」と付きます。

## フォルダの監視(ローカルとネットワークドライブ)

登録したフォルダは、種類に応じた方法で変更を検知します。

| フォルダの場所 | 検知の方法 |
| --- | --- |
| ローカルドライブ(固定ドライブ、リムーバブルドライブ) | ファイルの追加・変更を、すぐに反映します。 |
| ネットワークドライブ(NAS など) | 起動時に差分を確認し、そのあとは一定の間隔で確認します(定時ポーリング)。 |
| 種類を判別できないドライブ | 定時ポーリングで確認します。 |

ポーリングの間隔は、メニューの「設定 > 設定...」にある「NAS・ネットワークドライブの確認間隔」(1〜1440 分、既定は 10 分)で変えられます。詳しくは[インストールと初期設定](getting-started.md#設定)を参照してください。

## オフラインの動画

外付けHDDが接続されていないときなど、動画ファイルが見つからなくなっても、GrayBrowser は記録を消しません。その動画は「⚠ オフライン」と表示されて一覧に残り、記録とサムネイルも保たれます。オフラインの動画は再生できません。

- 登録しているフォルダ自体に届かないときは、左ペインの「フォルダ」の該当フォルダに「⚠」の印が付きます。フォルダが再び使えるようになると、元の表示に戻ります。
- スキャンや定時確認で、動画の大半が一度に見つからなくなったときは、保護のため、オフラインにしません。ドライブが一時的に外れた場合などに、記録がまとめてオフラインになるのを防ぐためです。

### 移動・ドライブ文字の変更への追従

動画ファイルを登録済みのフォルダの中の別の場所へ移したり、ドライブ文字が変わったりしたときは、スキャンなどで移動先に見つかったファイルを、オフラインになっている記録に自動で結び付けます。結び付けるのは、quick_hash(ファイルの一部から計算する高速なハッシュ)とサイズが一致する、オフラインの記録です。細かい条件までは、このガイドでは扱いません。

## 未登録パネル

ステータスバーの「未登録 N」を押すと開きます。登録されなかったファイルの一覧です。

現在、登録されない理由は「機種依存文字を含むファイル名」だけです。検出した文字も、行に表示されます。機種依存文字を含むファイル名は、通常のスキャンでは登録されません。

- 「名前を変更」: 新しいファイル名を入力して「OK」を押すと、ファイルの名前が変わり、そのまま通常の動画として登録されます。機種依存文字を取り除いた名前にしてください。名前を変えても登録されなかったときは、「名前は変更しました。登録は次回のスキャンで行われます。」と表示されます。
- エクスプローラーで名前を直した場合は、次回のスキャンで登録されます。

元のファイルが見つからない行には、「元のファイルが見つかりません」と表示され、ボタンが次の2つになります。

- 「名前を変更して登録」: 保管先に移したファイルなどを、名前を直して登録します。オフラインの動画として記録が残ります。
- 「一覧から削除」: その行を一覧から外します。

`.wb` ファイルの情報を引き継ぎたいときは、登録の前に `.wb` を取り込み直してください。手順は[旧WhiteBrowser(.wb)からの移行](wb-import.md)を参照してください。

## サムネイルとメタデータの生成失敗

ステータスバーの「生成失敗 N」を押すと開きます。サムネイルの生成やメタデータの取得に失敗した動画が、失敗の種類(「サムネイル生成失敗」「メタデータ取得失敗」)と失敗回数つきで並びます。

- 行ごとの「再試行」: その動画だけ、もう一度やり直します。
- 「未作成のサムネイルをすべて再作成」: サムネイルが無い動画を、まとめて作り直します。確認ダイアログに対象の件数が出ます。時間がかかることがあります。
- 「メタデータをすべて再取得」: メタデータ(解像度など)が無い動画を、まとめて取得し直します。確認ダイアログに対象の件数が出ます。

どちらも、対象が無いときは「再作成が必要なサムネイルはありません。」「再取得が必要なメタデータはありません。」と表示されます。FFmpeg / FFprobe が見つからないためにサムネイルが作られなかった場合は、PATH を通してから実行してください([インストールと初期設定](getting-started.md#ffmpeg--ffprobe-を用意する)を参照)。
