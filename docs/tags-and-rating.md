# タグ・レーティングの活用法

動画にタグと星(レーティング)を付けて、検索・絞り込み・並び替えで目的の動画を見つけるための使い方をまとめたガイドです。

関連ガイド: [README](../README.md) / [インストールと初期設定](getting-started.md) / [フォルダ登録・スキャンの詳細](folder-scan.md) / [重複ファイルの管理](duplicate-files.md) / [旧WhiteBrowser(.wb)からの移行](wb-import.md)

## タグを付ける

### 1本ずつ付ける

各動画の行の右側(詳細欄)で操作します。

1. 「タグを追加」と書かれた入力欄にタグ名を入力します。すでにあるタグは、入力中に候補として出ます。
2. 「追加」を押します。
3. 付いているタグは、動画の行にタグ名の札として並びます。外すときは、札の「×」を押します。

画面上部の「情報を隠す」を押すと、詳細欄(プロパティ・レーティング・タグ)を畳んで、サムネイルを広く見られます。もう一度押す(表示は「情報を表示」)と元に戻ります。

### まとめて付ける

複数の動画に同じタグを付けるときは、動画を選択してから右クリックします。

1. 動画を複数選択します([複数選択](#複数選択)を参照)。
2. 選択した動画のどれかを右クリックし、「タグを設定...(N 件)」を選びます。1件だけのときは「タグを設定...」と表示されます。
3. タグ名を入力するか、候補から選んで「OK」を押します。新しい名前も入力できます。

この操作で、タグが追加されます。すでに付いているタグが外れることはありません。

### タグ名の扱い

- 入力したタグ名は、自動で整えられます。全角の英数字と記号は半角に直り、前後の空白は取り除かれます(名前の途中の空白は残ります)。
- 大文字と小文字は区別されます。`Action` と `action` は、別のタグになります。

## タグを整理する

メニューの「タグ > タグの編集...」で、タグの一覧を整理します。

- 「↑」「↓」: タグの並びを入れ替えます。この並びが、左ペインの「タグ」の並びになります。並びは「保存」を押したときに確定します。「キャンセル」を押すと、入れ替えは破棄されます。
- 「削除」: 確認のあとで、タグを削除します。タグが付いていた動画からも外れます。こちらは「保存」を待たずにすぐ実行され、元に戻せません。
- タグの名前を変えることはできません。名前を変えたいときは、新しい名前のタグを付け直し、古いタグを削除してください。

## 星(レーティング)を付ける

動画の行の右側(詳細欄)にある星を押します。左から数えて、押した星の数がレーティングになります(星1〜5)。レーティングを外すときは、「クリア」を押します。

## 左ペインで絞り込む

画面の左側にある左ペインは、「フォルダ」「レーティング」「タグ」の3つのセクションからなります。見出しを押すと、セクションを開閉できます。開閉の状態は、次回の起動後も残ります。

| セクション | 使い方 |
| --- | --- |
| フォルダ | 登録しているフォルダを1つ選ぶと、そのフォルダの動画だけを表示します。「すべて」で絞り込みを解除します。 |
| レーティング | 「ALL」と、「★」から「★★★★★」までのボタンが並びます。複数を選べます。選んだレーティングのどれかと完全に一致する動画を表示します。たとえば「★★★」と「★★★★★」を選ぶと、星3つと星5つの動画が出ます(星4つの動画は出ません)。「ALL」で解除します。 |
| タグ | 複数のタグを選べます。選んだタグをすべて持つ動画だけを表示します。「すべて解除」で解除します。 |

レーティングの「ALL」は、レーティングでは絞り込まないという意味です。レーティングが付いていない動画だけを絞り込むボタンはありません。

フォルダ・レーティング・タグ・検索は、すべて組み合わせて使えます。そのときは、すべての条件に合う動画だけが表示されます。

## 検索

画面上部の検索ボックス(「検索...」)に入力すると、入力に合わせて一覧が絞り込まれます。「✕」を押すと、検索をクリアします。

- ファイル名、かな、ローマ字の部分一致で探します。ファイル名の一部を入れるだけで見つかります。
- 空白で区切って複数の語を入れると、すべての語に合う動画だけが残ります(AND)。
- タグ名やフォルダ名は、検索の対象ではありません。タグやフォルダで探すときは、左ペインを使ってください。
- 特別な検索構文(除外や OR など)はありません。

## 並び替えとジャンプ

画面上部の並び替えの項目と、昇順・降順のボタンで、一覧の並びを変えます。

- 並び替えの項目: ファイル名、追加日、更新日、レーティング、ファイルサイズ、フォルダ名
- 「昇順 ↑」「降順 ↓」: ボタンを押すたびに切り替わります。
- 「更新日」は、動画ファイルの更新日時です。GrayBrowser に登録した日時は、「追加日」です。

画面右下のステータスバーにある「ジャンプ」を押すと、一覧の 0% から 100% までの位置を、10% 刻みで選べます。大量の動画があるときに、一覧の途中へすばやく移動できます。

## 複数選択

動画の行のサムネイルをクリックして選択します。複数の動画をまとめて選ぶ操作は、次のとおりです。

| 操作 | 結果 |
| --- | --- |
| クリック | その動画だけを選びます。 |
| Ctrl + クリック | その動画の選択・解除を切り替えます。 |
| Shift + クリック | Shift を押さずに最後にクリックした動画から、クリックした動画までの範囲を選びます。 |
| Ctrl + Shift + クリック | 上と同じ範囲を、いまの選択に追加します。 |
| Ctrl + A | 表示中の動画をすべて選びます。 |
| Esc | 選択を解除します。 |

選択した件数は、ステータスバーに「N 件選択中」と表示されます。検索・並び順・絞り込みを変えると、選択は解除されます。

選択した動画を右クリックして、「タグを設定...」のほかに、「登録から削除」を選ぶこともできます。カタログから外すだけで、元の動画ファイルは削除されません。登録フォルダが監視・再スキャンの対象のままだと、次の更新チェックで再登録される場合があります。

## 動画を再生する

サムネイルをダブルクリックすると、OSの既定のプレイヤーで開きます。GrayBrowser には動画プレイヤーは入っておらず、プレイヤーを GrayBrowser の画面で指定する機能もありません。動画の形式に対応する既定のアプリが、Windows で設定されている必要があります。

オフラインの動画は再生できません。
