# 重複ファイルの管理

同じ動画が複数登録されているときに、それを見つけて、不要な方を整理する方法をまとめたガイドです。GrayBrowser は重複を自動で削除しません。内容を見比べたうえで、利用者が操作します。

関連ガイド: [README](../README.md) / [インストールと初期設定](getting-started.md) / [フォルダ登録・スキャンの詳細](folder-scan.md) / [タグ・レーティングの活用法](tags-and-rating.md)

## 重複パネルを開く

ステータスバーの「重複 N」を押すと、重複パネルが開きます。もう一度押すと閉じます。

「N」は、重複と判定された動画の延べ数です。たとえば、同じ動画が2つ登録された1グループなら、「重複 2」になります。

重複の検出は、アプリの起動時と、スキャンのあとに自動で行われます。結果をあらためて確認したいときは、パネルの「重複を再チェック」を押します。重複が見つかっていないときは、「重複候補は見つかっていません。」と表示されます。

## 重複の見つけ方

重複は、次の順で絞り込んで検出します。

1. quick_hash(ファイルの一部から計算する高速なハッシュ)とサイズが一致する動画を、候補として集めます。
2. 内容を確かめる必要があるグループだけ、full_hash(ファイル全体のハッシュ)で比べます。

ハッシュで比べるため、ファイル名が違っても検出の対象になります。

## グループの種類

グループの見出しに、次の4種類のどれかが表示されます。

| 見出し | 意味 |
| --- | --- |
| 内容一致（確定） | 内容が同じだと確認できています。 |
| パス衝突・内容確認済み | 同じパスに別のファイルが来たために作られたグループで、内容が同じだと確認できています。 |
| パス衝突・内容未確認 | 同じパスに別のファイルが来たために作られたグループで、内容が同じだと確認できていません(内容が違う場合も含みます)。 |
| 候補・内容未確認 | 内容が同じ候補ですが、確認できていません。この見出しには「NAS に接続できないため、内容が同じか確認できません」と添えられます。 |

「内容一致（確定）」と「パス衝突・内容確認済み」だけが、内容の一致が確認できているグループです。

## 行の見方

グループの中の動画は、登録日時の古い順に並びます。

各行には、サムネイル、パス、次の項目が表示されます。

- サイズ
- 再生時間
- 解像度
- 登録日時

サイズ・再生時間・解像度は、グループの中で値が違うものが強調されます。どれが大きいか、長いか、解像度が高いかを見比べて、残す方を決める手がかりにしてください。サムネイルをダブルクリックすると、動画を再生して中身を確認できます(オフラインの動画は再生できません)。

## 整理する

各行には、2つのボタンがあります。

| ボタン | 動作 |
| --- | --- |
| 登録解除 | カタログの登録だけを消します。元の動画ファイルは削除されません。GrayBrowser 上のタグ・レーティングなどの情報は失われます。 |
| ファイルを削除 | 動画ファイルをOSのゴミ箱へ移動し、カタログからも消します。ゴミ箱から元に戻せます。 |

どちらも、確認ダイアログが表示され、確定するまで実行されません。「登録解除」の確認は「登録を解除する」、「ファイルを削除」の確認は「ゴミ箱に移動して削除」を押すと実行されます。

### 「ファイルを削除」が使えないとき

次のいずれかに当てはまると、「ファイルを削除」は押せず、行にその理由が表示されます。

- 「オフラインのため削除できません」: その動画がオフラインのときです。
- 「内容の一致が確認できていないため削除できません」: 「内容一致（確定）」と「パス衝突・内容確認済み」以外のグループのときです。
- 「このグループで到達できる最後の1件のため削除できません」: グループの中で、接続できている動画が1件だけになったときです。重複の元になるファイルを、すべて失うことを防ぎます。

また、押せる状態でも、実行の時点で次の場合は拒否されます。

- ローカルの固定ドライブ上のファイルではない(ネットワークドライブや、リムーバブルドライブ上のファイル)
- 登録しているフォルダの外にあるファイル
- ファイルが見つからない
- ファイルのサイズが、登録したときと違う(この場合は、再スキャンを促すメッセージが表示されます)

拒否されたときは、理由が行に表示されます。ネットワークドライブやリムーバブルドライブ上の重複は、「登録解除」でカタログから外すか、エクスプローラーで直接整理してください。
