# GrayBrowser

![GrayBrowser](image/GrayBrowser-Banner.png)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![CI](https://github.com/becchi78/GrayBrowser/actions/workflows/ci.yml/badge.svg)](https://github.com/becchi78/GrayBrowser/actions/workflows/ci.yml)
![Status](https://img.shields.io/badge/status-alpha%20(0.10.1)-orange.svg)

大量のローカル動画ファイルを高速にスキャン・カタログ化し、タグ付け・レーティング・検索で整理できる、Windows向けのローカル動画管理デスクトップアプリです。

開発が停止したローカル動画管理ソフト「WhiteBrowser」の後継として、現代のPC環境・動画フォーマットに合わせて再構築しました。旧WhiteBrowserで不満の大きかった「ファイル追加時の検知・登録の遅さ」を解消し、大量の動画ファイルをストレスなく管理できることを目標にしています。

## ⚠️ 開発版に関する注意

現在のバージョンは **0.10.1(開発版)** です。破壊的変更や未発見の不具合が含まれる可能性があります。「ファイル > データベースをバックアップ」で手動バックアップを取れるので、大切な動画ファイルを扱う前に取得しておくことを推奨します(詳細は[docs/backup.md](docs/backup.md))。本番的な運用(このアプリのカタログ情報を唯一の管理手段にする等)は現時点では推奨しません。

## 主な機能

- **フォルダ登録・自動スキャン** — 指定した複数フォルダ配下の動画ファイルを検出し、データベースに登録します。フォルダ管理で、フォルダの並びを↑/↓で入れ替えたり、動画が増えないフォルダの「更新チェック」を個別にオフにしたりできます。機種依存文字を含むファイル名などで登録されなかったファイルは、ステータスバーの「未登録」パネルから、アプリ内でリネームして登録できます。
- **リアルタイム監視・自動追従** — ローカルドライブはファイルシステムイベントで即座に反映、NASなどのネットワークドライブは起動時差分スキャン＋定時ポーリング(間隔は「設定」メニューで変更できます)で検知します。ファイルの移動・ドライブレター変更にも自動追従します。
- **オフラインカタログ保持** — 外付けHDDなど未接続の媒体上の動画も、レコードとサムネイルを保持したまま「オフライン」として一覧に残します。
- **サムネイル自動生成** — FFmpegを使い、動画の代表シーン(再生時間の10%地点)からサムネイルをバックグラウンド生成します(WebP形式)。サムネイルが作られていない動画は、ステータスバーの「生成失敗」パネルから、まとめて再作成できます。生成中は、ステータスバーに進捗(完了件数/予定件数)が表示されます。
- **メタデータ取得** — FFprobeで解像度・コーデック・再生時間などを取得し、プロパティとして表示します。取得に失敗した動画は、「生成失敗」パネルから、まとめて再取得できます。
- **複数選択・一括操作** — 一覧でCtrl+クリック・Shift+クリック・Ctrl+Aにより複数の動画を選択できます。動画を右クリックして「タグを設定...」を選ぶと、選択した動画に同じタグをまとめて付けられます。「登録から削除」を選ぶと、選択した動画をまとめてカタログから外せます(元の動画ファイルは削除されません)。
- **重複ファイル検出** — ハッシュ値(quick_hash → full_hash)に基づき重複ファイルを検出し、一覧表示します。サイズ・再生時間・解像度を見比べて、不要な方を「登録解除」(カタログの登録だけを消す)するか、「ファイルを削除」(元の動画ファイルをOSのゴミ箱へ移動し、カタログからも消す)できます。自動削除はせず、削除は確認のうえユーザー操作で行います。内容の一致が確認できていないグループ、オフラインの動画、NASや外付けドライブ上のファイル、グループで最後の1件は、ファイルを削除できません。
- **インクリメンタル検索・ソート** — ファイル名・かな・ローマ字を横断したリアルタイム検索、タグ絞り込み、各種ソート(ファイル名・追加日・更新日・評価・ファイルサイズ・フォルダ名)。画面右下の「ジャンプ」ボタンで、一覧の0%〜100%の位置へ10%刻みで素早く移動できます。
- **左ペインの絞り込み** — 左ペインは「フォルダ」「評価」「タグ」の3セクションで、見出しをクリックして開閉できます(状態は再起動後も保持)。評価(星1〜5)とタグは、クリックで有効・無効を切り替える複数選択で、評価はそのどれかに一致する動画、タグは選んだタグを持つ動画に絞り込みます。フォルダ・評価・タグ・検索は、組み合わせて使えます。
- **タグ管理・レーティング** — 動画ごとに複数タグの付与・削除、星1〜5のレーティングが可能です。
- **タグの並び替えと削除** — 左ペインのタグ一覧の並びは、「タグ > タグの編集...」で↑/↓を使って自由に決められます。不要になったタグは、同じ画面から削除できます(付いている動画からも外れ、元に戻せません)。
- **データベースのバックアップ** — 「ファイル > データベースをバックアップ」で任意のタイミングにバックアップを取得できます。アプリ更新に伴うデータベース移行がある起動時は、移行の直前に自動でも取得します。復元手順は[docs/backup.md](docs/backup.md)を参照してください。
- **旧WhiteBrowser(.wb)データ移行** — `.wb`ファイルをパースし、パス・タグ・レーティング・旧サムネイルを本アプリへインポートできます。旧WhiteBrowserで評価に使われていた「★だけのタグ」はレーティングに変換し、取り込んだ動画のフォルダは(オフにしない限り)監視フォルダにも追加します。
- **アプリ内アップデート** — 「ヘルプ > 更新の確認...」で、新しいバージョンの有無とリリースノートを確認し、そのまま更新できます。起動時にも静かに確認します(「設定」でオフにできます)。更新は、利用者が「今すぐ更新」を押したときだけ行われ、署名を検証してから適用します。
- **動作ログの表示** — 「ヘルプ > 動作ログ...」で、現在のログをアプリ内で確認できます。新しい行への自動追従、レベルでの絞り込み、テキスト検索に対応しています。
- **ダークモード対応**

以下は対象外の機能です: アプリ内動画再生・スキン機能、Webリンクからの自動ダウンロード、音楽/画像/書庫ファイルの管理、CSV一括編集、再生回数・視聴日記録。

## 動作環境

- **OS:** Windows(64bit)
- **FFmpeg / FFprobe:** ⚠️ **本アプリには同梱されていません。** 事前にインストールし、PATHが通っている必要があります(サムネイル生成・メタデータ取得に使用)。未検出の場合はアプリ起動時に画面上で案内されます。
- **動画再生プレイヤー:** ⚠️ **本アプリには同梱されていません。** 動画再生はOS標準または任意の外部プレイヤー(設定画面で指定可能)に委譲します。
- **WebView2 Runtime:** Tauriアプリの表示に使用します(多くのWindows環境には標準で入っています)。

## インストール

[Releases](https://github.com/becchi78/GrayBrowser/releases/latest) ページから最新のインストーラー(`GrayBrowser_x.y.z_x64-setup.exe`)をダウンロードし、実行してください。管理者権限は不要です(ユーザー単位でインストールされます)。

> 開発版のため、現時点ではリリースが存在しない場合があります。ソースからのビルドは [開発者向けセットアップ](#開発者向けセットアップ) を参照してください。

### Windows SmartScreen の警告について

インストーラーはコード署名をしていないため、実行時に Windows SmartScreen の警告(「Windows によって PC が保護されました」)が表示される場合があります。ダウンロード元がこのリポジトリの [Releases](https://github.com/becchi78/GrayBrowser/releases) ページのファイルであることを確認したうえで、次の手順で進めてください。

1. 警告画面の「詳細情報」をクリックします。
2. 表示された「実行」ボタンをクリックします。

ダウンロードしたファイルが改ざんされていないかは、Releases ページのリリースノートに記載した SHA256 ハッシュと照合して確認できます。PowerShell で次のコマンドを実行し、出力されたハッシュがリリースノートの値と一致することを確認してください。

```powershell
Get-FileHash -Algorithm SHA256 .\GrayBrowser_x.y.z_x64-setup.exe
```

## 使い方

1. アプリを起動し、「フォルダを追加」から動画が入っているフォルダを登録します(複数登録可)。
2. 「スキャン開始」でフォルダ内の動画を検出・登録します。以降は新規ファイルの追加も自動的に検知されます。
3. サムネイルとメタデータはバックグラウンドで自動生成され、順次グリッドに反映されます。
4. 検索ボックスにファイル名の一部を入力すると、リアルタイムで絞り込まれます。タグでの絞り込みや、ファイル名・追加日・評価などでのソートも可能です。
5. 各動画の詳細欄からタグの付与・削除、レーティング(星1〜5)の設定ができます。
6. 動画をダブルクリック(またはメニューから再生)すると、OS標準または設定した外部プレイヤーで再生されます。
7. 重複ファイルが検出されると一覧に表示されます。削除は自動では行われず、内容を確認したうえで手動で行います。「ファイルを削除」では、元の動画ファイルがOSのゴミ箱へ移動され、ゴミ箱から元に戻せます。
8. 画面上部の「情報を隠す」で、各行の右側の詳細情報(プロパティ・評価・タグ)を畳んで、サムネイルを広く見られます。
9. 旧WhiteBrowserのデータがある場合は、「.wbインポート」から `.wb` ファイルと旧サムネイルフォルダを指定して移行できます。取り込んだ動画のフォルダは、デフォルトで監視フォルダに追加されます。

## 開発者向けセットアップ

```bash
# 依存関係のインストール
npm install

# 開発モードで起動(ホットリロード)
npm run tauri dev

# ビルド(インストーラ生成)
npm run tauri build
```

その他の主なコマンド:

```bash
# Lint / 型チェック / フロントエンド単体テスト
npm run lint
npm run typecheck
npm run test:unit

# Rust側のフォーマット・Lint・テスト
cargo fmt --check --all
cargo clippy --all-targets --workspace -- -D warnings
cargo test --all-features --workspace

# E2Eテスト(tauri-driver使用、手動実行)
npm run test:e2e
```

開発はWindows実機(またはWindows VM)を前提としています。

## アーキテクチャ・技術スタック

- **アプリフレームワーク:** Tauri v2(Rust + React/TypeScript + Vite)
- **データベース:** SQLite3(`rusqlite`、WALモード)
- **動画解析:** FFmpeg / FFprobe(PATH参照)
- **プロジェクト構成:** Cargoワークスペース(`crates/gb-core` = OS非依存ロジック、`src-tauri` = Windows/Tauri依存層)

コーディング規約・開発フローは [`CLAUDE.md`](CLAUDE.md) を参照してください。
