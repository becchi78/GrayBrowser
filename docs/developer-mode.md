# 開発者モード(開発版の受け取り)

開発者モードをオンにすると、安定版のリリースより前の「開発版」を、アプリ内の更新で受け取れるようになります。新しい機能を早めに試したい方、動作確認に協力していただける方向けの機能です。通常の利用では、オンにする必要はありません。

## 開発版とは

- 動作確認用の版で、**安定版ではありません**。不具合が残っている場合があります。
- バージョン番号は `0.18.0-dev.1` のように、`-dev.<番号>` が付きます。
- GitHub の Releases に、バージョンごとの Pre-release として公開されます。

## 使い方

1. 設定ダイアログの「開発者モード」をオンにします。オンの間は、画面にそれを示すバッジが表示されます。
2. 「ヘルプ > 更新の確認...」(または起動時の更新確認)で、更新を確認します。
3. 安定版と開発版の両方を確認し、**新しい版のほう**が提示されます。開発版の更新には「開発版」と表示されます。

オフに戻すと、以降は安定版だけが提示されます。すでに入れた開発版は、そのまま使い続けられます。安定版に戻したい場合は、より新しい安定版が公開されるのを待つか、[Releases](https://github.com/becchi78/GrayBrowser/releases) から安定版のインストーラーを手動で入れてください。

## データのバックアップについて

開発版の更新でデータベースの構造(スキーマ)が変わる場合、更新後の最初の起動で、移行の直前にデータベースが自動でバックアップされます(種別 `premigrate`、`backups/` フォルダ)。保存先、保持世代、復元手順は [データベースのバックアップと復元](backup.md) を参照してください。

次の点に注意してください。

- 自動バックアップが取られるのは、**スキーマの移行がある更新のとき**だけです。移行がない更新では取られません。
- 大切なデータがある場合は、開発版に更新する前に、「ファイル > データベースをバックアップ」で手動のバックアップを取っておくことをお勧めします。
- 開発版で新しい構造に移行したデータベースを、古い版に戻して使えるとは限りません。戻す場合は、バックアップから復元してください。

## 更新の安全性

開発版も、安定版と同じ公開鍵による署名の検証を通ったものだけが適用されます。更新の確認先はアプリに固定されていて、設定やフロントエンドから変更することはできません。仕組みの詳細は [リリースの仕組み](dev/release-process.md) を参照してください。
